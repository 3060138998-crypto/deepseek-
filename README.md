# deepseek-

Playground repository for a dsh-superagent deployment.

The agent works on this repository from GitHub issues and comments. Nothing here is production code.

## 如何运行

本仓库是实验仓库（playground），**不承载生产代码**，也没有需要构建、安装或部署的应用。

本地无需安装依赖或启动服务，直接阅读仓库文件即可。挂载在本仓库上的 dsh-superagent 部署会从 GitHub Issue 和评论中接手任务：在本仓库提交 Issue 或评论，就能看到它工作。

请把这里产生的一切都当作实验产物，不要用于生产环境。
